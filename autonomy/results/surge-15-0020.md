## Evidence Anchoring & Invariant Mapping
- **M-01 (Target-state driven):** Each test targets a resolved desired state (runit or openrc), not a mandatory sequential release path.
- **M-04 (Installation authoritative):** Test `SUN-ARTIX-RUNIT-001` uses the actual installed image hash, not a release label, to determine boot validity.
- **M-05 (Staged migrations):** Tests `SUN-ARTIX-RUNIT-003` and `SUN-ARTIX-RUNIT-004` prepare changes in `autonomy/results/` before any init system switch.
- **M-06 (Recoverable operations):** Test `SUN-ARTIX-RUNIT-007` provides a documented compensating procedure; rollback scripts reside at `autonomy/results/artix/runit/rollback_scripts/`.
- **M-09 (Repeatable re-running):** All test markdown files are idempotent; re-execution produces identical `sha256` hashes recorded in their respective evidence paths.
