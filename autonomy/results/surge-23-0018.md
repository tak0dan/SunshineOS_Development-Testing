**Recovery Procedure (runit):**  
1. Boot with `init=/usr/bin/runit-init`  
2. Run `sv enable <service>` to create symlink in `runsvdir/default/`  
3. Run `sv <service> start` to start supervision  
4. Validate via `sv status <service>` and `/var/log/runit/<service>/stat`  
5. Recovery compensating action: `sv down <service>` + remove symlink

**Test ID Reference:** `ART-BOOT-RUNIT-001` through `ART-BOOT-RUNIT-008`  
**Evidence Root:** `evidence/ART-BOOT-RUNIT-`  
**Related Mandate Invariant:** M-06 (recoverable operations), M-07 (historical artifacts archived)

**Recovery Procedure (openrc):**  
1. Boot with `init=/usr/sbin/openrc`  
2. Run `openrc-control start <service>` — reads `/etc/conf.d/local.start` + init scripts  
3. Validate via `openrc-control status <service>` and `/var/log/openrc/boot.log`  
4. Recovery compensating action: `openrc-control stop <service>` + revert `/etc/conf.d/local.start` changes

**Test ID Reference:** `ART-BOOT-OPENRC-001` through `ART-BOOT-OPENRC-008`  
**Evidence Root:** `evidence/ART-BOOT-OPENRC-`  
**Related Mandate Invariant:** M-06 (recoverable operations), M-01 (target-state driven migration)

## 3. Cross‑Init‑System Recovery Mapping

| SunshineOS Target | Artix Init | Key Recovery File | Migration Rule |
|-------------------|------------|-------------------|----------------|
| `systemd`-style service | runit | `/etc/runit/service/<name>/run` | Map `Type=simple` → `run` script with `exec` line |
| `systemd`-style service | openrc | `/etc/init.d/<name>.sh` | Map `ExecStart=` → `start()` function body |
| Target: sustainability | both | `/etc/conf.d/local.start` / `/etc/runit/1` | Preserve service ordering, avoid blind dependency removal (M-01, M-04) |

2. Parse service definitions using catalog rules (TC18 per mandate)
3. Stage recovery operations in `/tmp/sunshineos/migration‑staging/`
4. Validate via test IDs listed above before committing
5. Journal each step; compensating procedures exist per test ID
