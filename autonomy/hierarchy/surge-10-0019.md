- **Discovery:** Recursive `find` on `autonomy/`, `evidence/`, `openclaw/` for filenames matching `*runit*`, `*openrc*`, `*artix*`.  
- **Test IDs:** Assigned sequentially per init flavour and document type; prefixed with `ARTIX-RUNI-`, `ARTIX-OPENRC-`, or `COMP-RC-`.  
- **Evidence Paths:** All evidence artifacts stored under `evidence/artix/` or `evidence/compare/`. JSON/XML outputs from test scripts are included verbatim where present.  
- **Verification Status:** `PASSED` for all listed test IDs where exit code `0` was recorded and evidence hash matches `sha256sum` documented in the accompanying `.md` runbook.  
- **Limitations:** Some scripts (`004-*`) require root inside the VM and were skipped on the audit workstation. Those entries are marked `PENDING` in the full internal index (not shown here).
