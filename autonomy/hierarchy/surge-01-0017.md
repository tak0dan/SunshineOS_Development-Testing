## 6. Key Findings & Recommendations

| Finding | Implication | Action |
|---------|-------------|--------|
| Keyring supervise scripts lack explicit `timeout` in `run` (TEST-ARTIX-KR-020) | May cause boot stall if GPG agent is slow (violates M-05: staged migrations) | Add `timeout 30` to `evidence/audit/runit/keyring-supervise/run` |
| `etc/conf.d/keyring` depends on `network-online` but no `require` statement in openrc (TEST-ARTIX-KR-030) | Risk of keyring starting before network is ready | Add `require:! network-online` to the init script |
| Evidence hashes match across waves (M-09 repeatability) | Audit pipeline is stable | No change needed |
| runit compensating procedure documented but not auto-tested (M-06) | Recovery path unproven under interruption | Add `make test-compensate` target to CI |
