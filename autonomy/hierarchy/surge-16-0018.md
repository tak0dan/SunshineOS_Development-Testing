## 5. Verification & Recovery Protocol

1. **Discovery:** Run `artix-recovery-discover --init <runit|openrc>` — produces normalized snapshot.
2. **Planning:** Engine resolves transition catalog; outputs ordered operation graph.
3. **Staging:** All modifications applied to `/tmp/sunshineos-recovery-staging/`; no runtime mutation until approval.
4. **Execution:** `artix-recovery-execute --plan <plan-id>` — journals every step to `/var/log/sunshineos-recovery.journal`.
5. **Validation:** `artix-recovery-validate --run-tests` — runs TST-ART-*.REC suite; fails → automatic compensating procedure per M-06.
6. **Rollback:** If validation fails, `artix-recovery-rollback` restores from snapshot; evidence hashes remain unchanged.
