## 6. Verification & Recovery Workflow (Per M-06)

1. **Discovery** – Boot Artix ISO, capture current init system (`/etc/artix-release`), identify runit vs openrc.
2. **Staging** – Copy target recovery files to `/tmp/artix-recovery/` (never modify `/etc` in-place until validation).
3. **Validation** – Run test IDs `ART-BR-001` through `ART-BR-008` (runit) or `ART-BO-001` through `ART-BO-008` (openrc). Verify file integrity via SHA-256 hashes recorded in `evidence/artix-boot-recovery/cross/migration-signature.json`.
4. **Execution** – If all tests pass, apply recovery: `sv up /etc/sv/*` (runit) or `rc-service <service> start` (openrc).
5. **Journaling** – Log all operations to `/var/log/artix-recovery.log` (or `journalctl -t artix-recovery`).
6. **Recovery** – If validation fails at any step, execute compensating procedures:
   - runit: `sv down /etc/sv/*` → restore from backup hash.
   - openrc: `rc-update del <service> default` → restore `/etc/rc.conf` from etcd/versioned snapshot.
