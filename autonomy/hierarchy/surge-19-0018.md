## 5. Notes on Evidence Chain

- All `evidence/` artifacts are generated by `TODO/*.sh` test runners and committed with message format `TEST: <test-id> <description>`.
- Test IDs follow convention `ART-<INIT>-BT-<NNN>` where `INIT` = `RUNIT` or `OPENRC`.
- Evidence logs include `dmesg | grep -i 'runit\|openrc'` output, `journalctl -b -u runit-svc` or `rc-status` snapshots, and VM boot success/failure flags.
- Migration matrix (`migration-matrix.yaml`) is referenced by `evolution-engine/` for cross-release state reconstruction (see `reports/USER_MIGRATION_MANDATE_2026-11-21.md` invariants M-01, M-04, M-08).
